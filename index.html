01 / MY JOURNEY

From Student to Cybersecurity

I didn't start with everything figured out. I started with curiosity.

01

Where It Started

My technology journey began with my BCA studies, exploring programming, web development, databases, operating systems and computer networks. I was trying to understand how computers worked, and that curiosity gradually turned toward security.

02

Building Things

I turned theory into projects: weather forecasting, a to-do application, portfolio work, chatbot experiments and Flask-based applications. Debugging MongoDB, npm, Python dependencies, Git and deployment issues taught me that engineering is also about troubleshooting.

03

The Shift Toward Security

My curiosity moved from building applications to understanding how they could fail. I began studying authentication, authorization, IDOR, broken access control, Linux security, OSINT, penetration testing and security monitoring through controlled labs.

04

Linux & Security Labs

Kali Linux and practical labs introduced me to enumeration, Linux privilege escalation concepts, SUID, capabilities, sudo, hash cracking and web enumeration. I learned that tools matter less than understanding their output.

05

Networking Became the Foundation

I built Cisco Packet Tracer labs covering IP addressing, subnetting, VLANs, routing and inter-VLAN routing. Troubleshooting failed pings and routing problems taught me why networking knowledge is fundamental to cybersecurity.

06

AI CCTV Project

I worked on an AI-based CCTV surveillance system using Python, OpenCV, YOLOv8 and Flask. Real-time detection, video processing, recording, alerts, logging and a dashboard pushed me to combine software, monitoring and security.

07

Learning the SOC Mindset

Security alerts changed the way I investigate problems. I learned to ask who made a request, what source and destination were involved, which port and URL were used, which rule triggered, and whether the event needed further investigation.

08

Professional Experience

Internships and professional projects gave me experience with Python, PHP, Laravel, Node.js, Flask, SQL, MongoDB, Git and Linux. Real projects taught me that software must be usable, supportable and reliable—not merely functional.

09

Where I Am Now

Today my learning sits at the intersection of cybersecurity, networking, Linux, IT support and Python. My direction is toward penetration testing and cybersecurity while keeping a strong infrastructure and networking foundation.

10

Still Building

I don't see a perfect career path when I look back. I see experiments, failed attempts, projects, labs and lessons. I chose cybersecurity because I wanted to keep learning how systems work—and how they can be made safer.

I didn't start with everything figured out. I started with curiosity.
— Akshay Kumar
Cybersecurity & Network Security Enthusiast
