# Akshay Kumar — Portfolio

Personal portfolio of Akshay Kumar, System & Network Engineer, Researcher and aspiring penetration tester. Built with HTML, CSS and JavaScript.

**Live website:** [View portfolio](https://splendorous-cactus-88b8bd.netlify.app/)

## Latest portfolio package

[Download the updated portfolio ZIP](akshay-portfolio-profile-reference.zip)

This is the same package deployed to the live Netlify website. It includes the updated professional title, experience, skills, education, certifications, research highlights and project links, based on the GitHub and LinkedIn profiles.

## Open or deploy

1. Download and extract `akshay-portfolio-profile-reference.zip`.
2. Open `index.html` to preview the portfolio locally. Keep the `assets` folder beside it.
3. Upload the ZIP or its extracted contents to Netlify to deploy the static website. No build command is required.
